# ALUNIS

Nasceu enquanto eu estudava programação..

Depois de testar diferentes ferramentas de organização, percebi que nenhuma se adaptava à forma como eu realmente aprendo. Em vez de continuar procurando a ferramenta ideal, decidi criar a minha.

Além de desenvolver um software, este projeto registra a minha evolução como desenvolvedora. Cada funcionalidade surge conforme novos conhecimentos são aprendidos e aplicados.

---

## O que é?

O ALUNIS é um sistema pensado para acompanhar o processo de aprendizagem.

A ideia não é apenas organizar estudos, mas entender como eles acontecem. Com o tempo, os dados registrados servirão de base para dashboards e análises que ajudem a identificar padrões, acompanhar a evolução e apoiar melhorias no desempenho durante os estudos.

---

## Por onde estou começando

O desenvolvimento está começando pela tela de **Check-in**.

Antes de iniciar uma sessão de estudos, registro meu estado atual para criar um histórico que, futuramente, servirá de base para dashboards e análises sobre desempenho, evolução e hábitos de estudo.

Atualmente, o Check-in registra informações como:

- Energia
- Foco
- Disposição
